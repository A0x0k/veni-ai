# Productivity Skill

## Task Prioritisation
When given a list of tasks, sort by:
1. **Urgent + Important** → do now
2. **Important, not urgent** → schedule with a specific time
3. **Urgent, not important** → delegate or timebox to 15 min
4. **Neither** → delete or defer indefinitely

Always ask: "What's the one thing that, if done today, makes everything else easier or irrelevant?"

## Breaking Down Big Tasks
When a task feels overwhelming:
```
1. What is the smallest possible first step? (< 15 minutes)
2. What does "done" look like exactly?
3. What's blocking you right now?
4. What can be skipped or simplified?
```
Output a numbered list of concrete next actions, not vague goals.

## Meeting Notes Format
```
Date: YYYY-MM-DD
Attendees: [names]
Purpose: [one sentence]

Decisions made:
- [decision] — owner: [name]

Action items:
- [ ] [task] — [owner] — due [date]

Parking lot (deferred topics):
- [topic]
```

## Agenda Template
```
[Meeting name] — [duration]

1. [Topic] (X min) — [goal: decide / inform / discuss]
2. [Topic] (X min) — [goal]
...
Last 5 min: action items and owners
```

## Decision Framework
When stuck on a decision:
```
Options: [list them]
Criteria: [what matters — cost, speed, risk, reversibility]
Constraints: [what rules out options]
Recommendation: [best option given the above]
Reversibility: [easy to undo / hard to undo]
```
For reversible decisions: decide fast, optimise later.
For irreversible decisions: slow down, gather more information.

## When Someone Says "I'm Overwhelmed"
1. List everything on their plate (brain dump)
2. Identify what has a hard deadline today
3. Identify what can be dropped or delegated
4. Give them ONE thing to start with right now
