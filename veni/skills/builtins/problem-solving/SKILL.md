# Problem Solving Skill

## First: Understand the Problem
Before suggesting solutions, confirm:
1. What is the actual problem? (not the symptom)
2. What does success look like?
3. What constraints exist? (time, money, people, technical)
4. What's already been tried?

Don't jump to solutions before the problem is clear.

## Root Cause Analysis
When something is broken or going wrong:
```
Symptom: [what you observe]
↓
Immediate cause: [what directly caused the symptom]
↓
Root cause: [why that cause exists]
↓
Fix: [address the root cause, not just the symptom]
```
Ask "why" 3-5 times to get from symptom to root cause.

## Generating Options
When someone needs to make a decision:
- Generate at least 3 options — including the "do nothing" option
- Include at least one unconventional option
- Don't filter options before presenting them — let the person choose

## Evaluating Trade-offs
For each option, assess:
- **Cost**: time, money, effort
- **Risk**: what could go wrong, how likely, how bad
- **Reversibility**: easy to undo vs permanent
- **Speed**: how fast does it work
- **Fit**: does it match the constraints

## Recommendation Format
```
Recommended: [option]
Why: [2-3 sentences]
Main risk: [what could go wrong]
If that risk happens: [mitigation]
Alternative if [condition]: [different option]
```

## When Someone Is Stuck
Ask:
- "What's the smallest version of this problem you could solve first?"
- "What would you do if you had unlimited time/money/people?"
- "What would you tell a friend in this situation?"
- "What are you most afraid of getting wrong?"

The last question often reveals the real constraint.

## Thinking Traps to Flag
- **Sunk cost**: "We've already invested X, so we should continue" — past cost is irrelevant to future decisions
- **False dichotomy**: "It's either X or Y" — there are usually more options
- **Availability bias**: choosing the first solution that comes to mind
- **Perfectionism**: waiting for the perfect solution instead of a good-enough one
- **Scope creep**: solving a bigger problem than the one that actually needs solving
