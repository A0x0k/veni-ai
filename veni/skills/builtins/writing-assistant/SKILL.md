# Writing Assistant Skill

## Before Editing, Identify the Goal
Infer from context:
- Who is the reader? (colleague, customer, manager, public)
- What should the reader *do or feel* after reading?
- What tone fits? (formal, professional-casual, friendly)

Don't change tone without stating what you changed and why.

## Editing Priorities (in order)
1. **Clarity** — can the reader understand it in one pass?
2. **Concision** — remove words that add length without meaning
3. **Tone** — match the audience and purpose
4. **Grammar/spelling** — fix last, not first

## Clarity Rules
- One idea per sentence — split sentences joined by "and" that cover unrelated ideas
- Put the main point first — don't bury the ask in paragraph 3
- Replace vague words: "soon" → specific date, "some" → a number, "issues" → what specifically
- Active voice: "The team shipped the feature" not "The feature was shipped by the team"

## Concision — Replace These
| Wordy | Concise |
|---|---|
| "In order to" | "To" |
| "Due to the fact that" | "Because" |
| "At this point in time" | "Now" |
| "Please do not hesitate to contact me" | "Feel free to reach out" |
| "I wanted to reach out to..." | "I'm writing to..." |
| "It is important to note that" | (delete it) |
| "As per my previous email" | "As I mentioned" |
| "Going forward" | "From now on" |

## Templates by Type

**Professional email:**
```
Subject: [Action needed by DATE] or [FYI: topic]

[One sentence: why you're writing]
[Body: one paragraph per point, max 3]
[Close: who does what by when]
```

**Slack/Teams message (short):**
```
[Context in one sentence if needed]
[The actual ask or update]
[Next step if any]
```

**Apology:**
```
[Acknowledge what happened — no "if you were offended"]
[Take responsibility without excuses]
[What you're doing to fix it]
[What changes going forward]
```

**Announcement:**
```
[What's changing and when — first sentence]
[Why it's changing]
[What people need to do, if anything]
[Who to contact with questions]
```

**Performance review / self-assessment:**
```
[Achievement] → [Measurable impact]
Use numbers: "reduced load time by 40%" not "improved performance"
```

## Tone Calibration
- **Formal**: passive voice acceptable, full sentences, no contractions, titles used
- **Professional-casual**: active voice, contractions OK, direct, first names
- **Friendly**: short sentences, conversational, emoji acceptable if context allows

## What NOT to Do
- Don't add filler phrases: "I hope this email finds you well"
- Don't hedge everything: "It might possibly be the case that perhaps..."
- Don't use passive voice to avoid accountability: "Mistakes were made"
- Don't write a wall of text — break into paragraphs of max 4 sentences
