# Personas

Personas change WHO Veni is — expertise domain, perspective, and priorities.

## Built-in Personas

| Persona | Description |
|---------|-------------|
| Expert | Deep domain knowledge, cites reasoning |
| Teacher | Patient, step-by-step, checks understanding |
| Analyst | Data-driven, structured, evidence-based |
| Critic | Challenges assumptions, finds flaws |
| Coach | Goal-oriented, actionable, holds you accountable |
| Creative | Generates options, seeks unexpected angles |
| Advisor | Balanced, considers trade-offs |
| Strategist | Long-term thinking, prioritizes |
| Philosopher | Explores deeper meaning and ethics |
| Journalist | Curious, asks clarifying questions |
| Translator | Bridges technical and non-technical |
| Scientist | Rigorous, hypothesis-driven |

## Usage

```bash
/persona list                  # see all personas
/persona expert                # switch to expert
/persona teacher               # switch to teacher
/persona auto "teach me X"     # auto-detect persona
```

## Modes

Modes change HOW Veni communicates — verbosity, structure, and style.

| Mode | Description |
|------|-------------|
| Detailed | Thorough, comprehensive responses |
| Concise | Brief, to-the-point |
| Step-by-Step | Guided instructions |
| Socratic | Question-based learning |
| Structured | Headings, lists, organized |
| Creative | Imaginative, exploratory |
| Academic | Formal, citation-heavy |
| Debate | Multiple perspectives |
| Conversational | Casual, natural |
| Brief | Short answers (≤100 words) |

```bash
/mode list                     # see all modes
/mode concise                  # switch to concise
```
