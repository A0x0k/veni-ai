# Veni AI

**A focused terminal AI assistant for repo work.**

Veni AI is a terminal-native assistant for repo-aware chat, controlled shell execution, file editing, and project search.

## Quick Start

```bash
pip install veni-ai
veni init
veni chat
```

## Key Features

- **Multi-Provider** — Ollama, OpenAI, Gemini, Anthropic, Groq, DeepSeek, Qwen, OpenRouter, Mistral, Perplexity, DuckDuckGo, and a Free tier
- **Rich Terminal UI** — Streaming responses, live token dashboard, themes
- **Skills System** — 21 built-in skills that auto-activate based on context
- **Personas & Modes** — Switch AI behavior with 11 personas and 10 response modes
- **Safety First** — Approval gates, workspace isolation, PII redaction
- **Extensible** — Plugin system, MCP support, custom skills
