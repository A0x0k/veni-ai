# Skills System

Veni AI ships with 21 built-in skills that activate automatically based on context.

## Developer Skills

- Code Review
- Debugging
- Git Workflow
- Refactoring
- Database
- Testing
- Security Audit
- Python Web Dev
- DevOps & CI/CD
- Shell Scripting

## Data Skills

- Data Analysis
- Jupyter
- ML Workflow
- Log Analysis

## General Skills

- Explain Code
- Writing Assistant
- Research Assistant
- Productivity
- Learning Assistant
- Problem Solving
- Documentation

## Usage

```bash
/skill list                    # see all skills
/skill search django           # find skills by keyword
/skill enable code-review      # manually enable
/skill disable debugging       # manually disable
/skill auto "how do I test?"   # auto-detect
```
