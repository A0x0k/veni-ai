# Tools

Veni AI provides 12 AI-accessible tools for the agent to use:

| Tool | Description |
|------|-------------|
| Shell | Execute shell commands with approval gates |
| File Read | Read files from the workspace |
| File Write | Write and edit files |
| Search | Search the codebase and web |
| Browser | Playwright-based web browsing |
| Vision | Analyze images and screenshots |
| Voice | Speech input/output |
| Image Gen | Generate images |
| Web Intelligence | Smart web research |
| Repo Map | Map project structure |
| Doc Lookup | Look up documentation |
| Diff | Compare file versions |
